# เสน่ห์วัฒนธรรมไทย (Charm of Thai Culture) 🇹🇭

> เว็บไซต์เพื่อการศึกษาเรื่องวัฒนธรรมไทย ออกแบบสำหรับนักเรียนและนักศึกษา สวยงาม ทันสมัย สีสันสดใส อ่านง่าย และรองรับการแสดงผลบนสมาร์ตโฟน (Responsive Web Design)

## 📖 เกี่ยวกับโครงการ (About the Project)

**"เสน่ห์วัฒนธรรมไทย"** เป็นเว็บแอปพลิเคชันเพื่อการศึกษาที่รวบรวมองค์ความรู้ด้านวัฒนธรรมไทยที่สำคัญ 4 มิติหลัก พร้อมระบบแบบทดสอบวัดผลและออกเกียรติบัตรออนไลน์จำลอง มุ่งเน้นการถ่ายทอดคุณค่ามรดกทางปัญญาของชาติสู่คนรุ่นใหม่และเยาวชน

### 🌟 ฟังก์ชันและเนื้อหาหลักภายในเว็บไซต์
1. **หน้าแรก (Home)**
   - ทัศนียภาพวัฒนธรรมไทยริมแม่น้ำเจ้าพระยา (วัดอรุณราชวรารามและพระบรมมหาราชวัง)
   - ภาพรวม 4 เสาหลักแห่งอัตลักษณ์ไทย และคุณค่าซอฟต์พาวเวอร์ไทย (Thai Soft Power)
   - เกร็ดน่ารู้สั้นๆ ชวนคิดสำหรับคนรุ่นใหม่ (Did You Know?)
2. **หน้าประเพณีไทย (Thai Traditions)**
   - เจาะลึกประเพณีสำคัญ: **สงกรานต์** (มรดกภูมิปัญญาทางวัฒนธรรมที่จับต้องไม่ได้ของมนุษยชาติ UNESCO 2566), **ลอยกระทง**, **แห่เทียนพรรษา**, **ผีตาโขน**, และ **บุญบั้งไฟ**
   - ประวัติ ความสำคัญ พิธีกรรม และแนวทางปฏิบัติอย่างสร้างสรรค์และรักษ์สิ่งแวดล้อม
3. **หน้าอาหารไทย (Thai Cuisine)**
   - อาหารไทยยอดนิยมระดับโลก: **ต้มยำกุ้ง**, **ผัดไทยกุ้งสด**, **แกงมัสมั่นไก่**, **ส้มตำไทย**, **ข้าวเหนียวมะม่วง**, **แกงเขียวหวาน**
   - แสดงมิติรสชาติ ระดับความเผ็ด ประวัติความเป็นมา และวัตถุดิบ
   - ศาสตร์ "อาหารเป็นยา" เจาะลึกสรรพคุณสมุนไพรไทย เช่น ข่า, ตะไคร้, ใบมะกรูด, กะเพรา, โหระพา, มะขามเปียก
4. **หน้าการแต่งกายไทย (Thai Costumes)**
   - **ชุดไทยพระราชนิยม** 8 แบบหลัก (ชุดไทยจักรี, ชุดไทยเรือนต้น, ชุดไทยบรมพิมาน, ชุดไทยศิวาลัย, ชุดไทยจิตรลดา, ชุดไทยจักรพรรดิ ฯลฯ)
   - ภูมิปัญญาผ้าทอไทย 4 ภาค (ผ้าไหมมัดหมี่, ผ้ายกลำพูน, ผ้าซิ่นตีนจก, ผ้าฝ้ายเข็นมือ)
   - คำแนะนำโอกาสในการสวมใส่สำหรับนักเรียนนักศึกษา
5. **หน้ามารยาทและเอกลักษณ์ไทย (Thai Etiquette & Identity)**
   - คู่มือ **การไหว้ 3 ระดับ** (ไหว้พระรัตนตรัย, ไหว้บิดามารดา/ครูอาจารย์, ไหว้บุคคลเสมอกัน) พร้อมตำแหน่งนิ้วและองศาการก้มที่ถูกต้อง
   - การกราบเบญจางคประดิษฐ์ และมารยาทการเดินผ่านผู้ใหญ่
   - 4 อัตลักษณ์ทางจิตใจ: รอยยิ้มสยาม, ความกตัญญู, น้ำใจไทย, และความเกรงใจ
6. **หน้าแบบทดสอบความรู้ 5 ข้อ พร้อมเฉลย (Cultural Quiz)**
   - แบบทดสอบวัดความรู้ 5 ข้อ พร้อมตรวจคำตอบและแสดงเฉลยละเอียดทันที
   - ระบบคำนวณคะแนนและระดับประเมินความรอบรู้
   - **ระบบออกเกียรติบัตรออนไลน์จำลอง**: สามารถกรอกชื่อ-นามสกุลของผู้เรียนเพื่อสร้างและสั่งพิมพ์ (Print/Save PDF) เกียรติบัตรสำหรับใส่แฟ้มสะสมผลงาน (Portfolio)

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

- **Frontend Framework**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler & Build Tool**: [Vite 8](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Typography**: Google Fonts ภาษาไทย ([Prompt](https://fonts.google.com/specimen/Prompt) สำหรับหัวข้อ และ [Sarabun](https://fonts.google.com/specimen/Sarabun) สำหรับเนื้อหา)
- **Deployment**: รองรับทั้ง GitHub Pages, Vercel, Netlify และ AI Studio

## 🚀 วิธีการติดตั้งและรันในเครื่อง (Getting Started)

### ข้อกำหนดเบื้องต้น (Prerequisites)
- ติดตั้ง [Node.js](https://nodejs.org/) (เวอร์ชัน 18 ขึ้นไป แนะนำ Node.js 20 LTS)
- ติดตั้ง [Git](https://git-scm.com/)

### 1. คัดลอกโครงการ (Clone Repository)
```bash
git clone https://github.com/<your-username>/<your-repo-name>.git
cd <your-repo-name>
```

### 2. ติดตั้ง Dependencies
```bash
npm install
```

### 3. รันโปรเจกต์ในโหมดพัฒนา (Development Mode)
```bash
npm run dev
```
เปิดบราวเซอร์ไปที่ `http://localhost:3000`

### 4. บิลด์สำหรับ Production
```bash
npm run build
```
ไฟล์ที่พร้อมเผยแพร่จะถูกสร้างไว้ในโฟลเดอร์ `dist/`

## 🌐 วิธีนำขึ้น GitHub และเผยแพร่บน GitHub Pages

### ขั้นตอนที่ 1: อัปโหลดโค้ดขึ้น GitHub
1. สร้าง Repository ใหม่บน GitHub (เช่น ชื่อ `thai-culture-charm`)
2. ในเครื่องของคุณ รันคำสั่งต่อไปนี้:
```bash
git init
git add .
git commit -m "feat: initial commit for Thai Culture educational website"
git branch -M main
git remote add origin https://github.com/<your-username>/thai-culture-charm.git
git push -u origin main
```

### วิธีการใช้งานในรูปแบบไฟล์ HTML (Static HTML):

โครงการนี้มีไฟล์ HTML สำเร็จรูปที่สามารถเปิดใช้งานหรือนำขึ้น GitHub ได้ทันที 2 รูปแบบ:

1. **เปิดดูในเครื่องทันทีโดยไม่ต้องติดตั้งโปรแกรม (Standalone HTML)**
   - ดับเบิลคลิกเปิดไฟล์ `standalone.html` บนเว็บเบราว์เซอร์ใดก็ได้ (Chrome, Edge, Safari, Firefox)
   - ใช้งานได้ทันที มีเนื้อหาครบทุกหน้า พร้อมแบบทดสอบและระบบพิมพ์เกียรติบัตร

2. **เผยแพร่บน GitHub Pages แบบไม่ต้องรัน Build (ผ่านโฟลเดอร์ `/docs`)**
   - ในโฟลเดอร์ `docs/` มีไฟล์ `index.html` จัดเตรียมไว้แล้ว
   - บนหน้า GitHub ของคุณ ไปที่ **Settings** > **Pages**
   - ในส่วน **Source** เลือก **Deploy from a branch**
   - เลือก Branch: `main` และโฟลเดอร์: `/docs` แล้วกด **Save**
   - เว็บไซต์จะออนไลน์ทันทีโดยไม่ต้องใช้ Node.js หรือ GitHub Actions

3. **เผยแพร่ผ่าน GitHub Actions (Vite + React)**
   - บนหน้า GitHub ไปที่ **Settings** > **Pages**
   - ในส่วน **Source** เลือก **GitHub Actions** (ระบบจะรัน `.github/workflows/deploy.yml` ให้อัตโนมัติ)
